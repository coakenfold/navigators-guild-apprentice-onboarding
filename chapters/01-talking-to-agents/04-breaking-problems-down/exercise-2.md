> Take this project idea: "A tool for planning road trips. Enter your start and end points, add stops along the way, and see the total driving time." Write out the user stories. Each story should be one thing a user does.

- Start → end drive time: enter two places and see the total driving time
- Add stops: add stops along the way and see the total update
- Edit stops: remove a stop or move it up or down, and the total updates
- Leg breakdown: see the time for each leg as well as the total
- Keep my trip: reload the page and still see the trip

As a user I want to enter start and destination points to see the route and total driving time

As a user I want to add stops to an existing route and see the route and total driving time update

As a user I want to edit stops (remove, reorder) on an existing route and see the route and driving time update

As a user I want to see the time of each leg of a trip so that I know how long it will take between stops

As a user I want to reload the page and see my existing route so that I don't lose them
